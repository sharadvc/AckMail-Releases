# AckMail v1 beta 1

An early beta of the native AckMail macOS email app.

## Download and install

Download AckMail-v1-beta.1-macos-arm64.zip, extract it, and move AckMail.app into Applications.

- Apple Silicon (M1 or newer) only. Intel Macs are not supported by this build.
- macOS 14 or later.
- Development-signed, not Developer ID signed or notarized. Gatekeeper assessment currently rejects this build. This is an early tester build, not a frictionless public installer. Do not disable Gatekeeper globally.
- Use only if you trust the publisher and are comfortable testing prerelease software.

## Beta notes

Unified mail accounts, native mail reading/composing, optional AckAI, scheduling, and privacy controls. Provider authentication requirements apply. AI providers may charge separately. Scheduled sends need AckMail running and connected.

This release packages the installed build from 15 November 2026. Its internal app version remains 0.1 (build 1); v1-beta.1 is the distribution label. It does not include subsequent unbuilt source edits. No personal mail databases, account settings, or Keychain credentials are included.

The source repository remains private. This repository distributes beta binaries only; source archives generated by GitHub contain only release documentation.

Verify the ZIP against SHA256SUMS.txt before installing. Please report reproducible issues without including passwords, tokens, or private email content.
